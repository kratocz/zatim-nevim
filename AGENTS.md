# AGENTS.md

Guidance for AI coding agents working in this repository (Claude Code, Cursor, Aider, Copilot, …).

## Project overview

Personal learning log — one person's from-scratch notes on learning **vim / neovim / LazyVim**.
This is **not** a software project and **not** an official vim course; it's a growing notebook
of lessons, a cheatsheet, progress tracking, and practice files. The repo name *„zatím nevím"*
is a Czech pun on *„I don't know yet"* with *vim* hidden inside.

## Struktura

- `README.md` — rozcestník a vysvětlení účelu.
- `progress.md` — tracker postupu (checkboxy fází 0–3).
- `cheatsheet.md` — gramatika vim (módy, operátory, pohyby, text objekty).
- `lekce/NN-nazev.md` — postupné lekce, číslované.
- `cviceni/NN-nazev.txt` — cvičné soubory k procvičování zásahů (bezpečné hřiště).

N/A — je to repo s poznámkami, nic se nebuilduje ani netestuje.

## Conventions

- **Jazyk obsahu:** čeština (lekce, cvičení, poznámky). Výjimka: horní disclaimer v `README.md`
  a tento „Project overview" jsou anglicky, aby cizinci pochopili účel a nespletli si repo
  s oficiálním zdrojem.
- **Lekce i cvičení číslovat** `NN-nazev` (`01-preziti`, `02-gramatika`, …) kvůli řazení.
- **Cvičné soubory neničit nevratně** — originály jsou v gitu, k obnovení `git checkout <soubor>`.
- Nové lekce přidávat postupně, tempo drží uživatel; aktualizovat odkaz „Co dál" v předchozí lekci.
