# Track B — Přechod z IDE

Goal-oriented kapitola pro lidi přicházející z **VS Code** nebo **JetBrains**. Každá lekce
odpovídá na reálný dotaz *„jak ve vim udělám to, co v IDE dělám takhle"*. Nepředpokládá se
lineární čtení — skoč na to, co zrovna potřebuješ.

Pokud jsi nováček úplně od nuly, začni radši [Trackem A](../lekce/) (kurz od nuly).
